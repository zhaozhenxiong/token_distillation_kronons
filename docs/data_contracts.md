# 数据和目录契约

学生输入固定为 `open, high, low, close, volume, amount`，日线、原始价格口径、股、人民币元。股票范围为沪深 A 股；北交所与 B 股不会进入此初版研究人口。源数据库和官方模型只读引用。

`StudentWindow` 绑定单股、预测原点、context 日期与矩阵、实际可用时间、完整未来矩阵及 label_end/label_mature_at。窗口必须与独立核验日历逐个会话相符；当前对停牌/缺行情直接拒绝，不补值。纯日期 as_of 表示当地15:00；明确的盘中时刻不得消费当天完整日线。源库缺 available_at 时只推定15:00收盘可用，不宣称具有真实到达/修订时间证据。

窗口原点后的数据只生成未来标签，归一化仅拟合 context 的 float64 均值与标准差，未来复用它们。未来不足返回 None 和原因，不能当作“横盘”负类。数据集绑定每个原点的归一化统计量；训练/评估以冻结官方 tokenizer 对 context 单独编码及 context+future 编码逐样本核验前缀 token 完全相等，不通过则停止。

`TeacherLabel` 用 mask 区分有效零值与未知；有效标签必须有 dependency_start/end、available_at、label_end 和 label_mature_at。`TeacherSample` 要求所有有效依赖落在学生可见窗口，且可用/成熟时点不晚于 as_of。JSON 教师记录的未来标签字段为 null，其历史依赖和确认时点单独记录。统一样本的 `teachers` 具有 `w32 / czsc / ict` 三个监督组，分别代表 CZSC 量价、原生结构和 ICT 原子事实。每组保留独立 schema、逐项值和 masks；未知值规范为 null。训练按有效元素选择后才计算 Huber/BCE。

时间段顺序固定为 train、tune、calibration、policy、holdout。纯日期段末解释为当日最后微秒；标签跨越段末或未在段内成熟均排除。每次生成冻结显式股票人口、时间边界、实际读入行和标签观察截止，并记录候选数、尝试数、剔除原因及教师覆盖率。人口数量上限未尝试的样本不算数据失败。留出仍声明为回溯开发隔离段，不作“从未使用过”的前瞻留出声明。

数据集目录保存 `manifest.json` 与五个 `<split>.jsonl`。清单记录配置、源码、独立日历、股票行快照、教师 schema/覆盖率及分片 SHA；样本记录实际原始/归一化数组、时间特征、未来收益方向、依赖、教师目标及 masks、来源行和内容 SHA。读取时核验清单、分片、样本、人口哈希及内部因果语义。token 仅在显式训练/评估中编码到内存，当前不保存 token cache。

`filter-dataset` 可从冻结父集显式派生标签质量子集，只排除未来标签区间的可疑未复权隔夜断点。它沿用冻结W32的15%主板/25%创业板科创板阈值；不确认公司行动、不复权、不改原始价格或保留样本字节。清单保存父集/政策/代码哈希及排除明细。这项筛选使用标签成熟后的信息，是事后研究准入，不得描述为预测原点可执行的过滤器。

当前模型只收到归一化token与日期，归一化mean/std保存在数据记录中但未提供给内部头。`tests/test_identifiability.py` 的金融量纲一致反例证明：价格平移、金额同步调整后，归一化上下文与未来可完全一致，原始百分比收益类别却从上涨变为横盘。此为表征信息缺失的数学限制，不是整个市场或当前实测误差的因果归因。外部反归一化可以恢复不同的价格坐标，现有直接方向头不能保证恢复这一信息。

训练检查点及完整实验状态写 `artifacts/runs/` 或 `artifacts/checkpoints/`，评价写 `artifacts/reports/`。当前检查点保存 LoRA、内部头和优化器，不复制官方基座和 tokenizer；它绑定数据清单、配置文件、资产、教师 schema 和运行时代码的 SHA，重载时必须一致。恢复训练尚未实现，优化器状态只作留档。未来独立导出写 `artifacts/exports/`，须验收合并等价性、tokenizer 引用、校准与资格谱系，以及禁止在线教师调用的部署环境。
