## 2026-10-19 扩样与四组多种子消融

已完成20只沪深股票、四组教师模式、三个固定种子（42/123/2026）的12次独立训练及检查点重载评估。每组使用MPS、512次优化器更新、batch 4，共6,144次更新；每组2,048次样本呈现，相当于1,024个训练窗口的两遍。相比此前三股、24步通路验证，扩大了股票数、覆盖年份和训练预算；由于人口和时期改变，不能将两次试验的绝对指标变化归因于扩样。

本轮冻结数据集为`ablation_20261019_v2`，五段样本数为1,024/311/133/209/480，总计2,157。20股按训练前2023年成交额和历史覆盖准入，属于固定便利样本，不是无幸存者偏差的全市场人口。原始读入快照截至2026-10-16；实际留出预测原点为2026-04-08至09-22，最后标签成熟于09-30。各阶段结束后才成熟的标签均被清洗，不能把请求区间终点当成最后实际留出原点。

父数据集保留不动。派生数据仅剔除了`002594.SZ / 2025-07-23`一个tune窗口：其未来标签区间出现337元前收至112.01元开盘的可疑未复权断点，原因未确认；未读取复权因子或修复价格。train和holdout人口未变，保留样本字节未变，未补齐样本上限。此筛选使用未来标签信息，结论只适用于该事后质量准入人群，不能把它当成预测时可用的过滤规则。

四组共用AR及方向损失、相同LoRA与完整内部头，均关闭冻结基座KL；`none`没有辅助教师损失。三个教师组的辅助系数总和固定为0.6。所有同种子组的初始化和实际样本顺序哈希一致；统一每128步用tune方向LogLoss选择检查点，并允许step 0。12组均完整训练至512步、最终都选择256步，因此本轮比较没有所选步数不同的混杂。

当前弱于方向先验的证据与解释边界如下：

- **概率偏差是直接可见的误差来源。** 无教师平均预测概率为下跌36.23%、平盘19.64%、上涨44.13%，实际比例为47.29%/11.25%/41.46%。按真实类别分解，LogLoss相对先验的下跌/平盘/上涨贡献为+0.061259/-0.036001/+0.014953，合计+0.040211。教师只轻微修正该偏差。这是算术误差分解，不是独立校准检验或全部因果解释。
- **教师进入主干的影响有限。** 选中检查点的有效LoRA相对无教师差异范数，仅为原始q/v权重范数的0.03693%/0.05930%/0.04380%；完整LoRA适配约0.89%。单个训练批次也显示教师共享LoRA梯度较小、最终方向与教师梯度存在局部冲突；这支持后续检查目标权重与训练阶段，不能单凭范数或单批次梯度证明预测效用。
- **稀有事件仍未超越简单常数。** 1,024个训练窗口中，七类W32事件各仅2至15个正例；事件BCE劣于训练频率常数，说明降低辅助损失还不足以证明事件知识获取。
- **输入存在已证明的可辨识性缺口。** 内部头仅接收归一化token和时间，没有窗口均值/标准差。合成反例中，价格整体平移并同步调整成交额后，归一化上下文与未来完全相同，原始5日收益却为1.32%与0.24%，对应不同方向标签。它证明百分比目标可能缺少输入信息，不能证明该问题解释了全部真实误差；真实量额关系可能保留部分价格尺度信息。
- **增加步数没有持续改善方向。** 各组256步后tune指标回升；连续事实重建继续改善与方向泛化改善不是同一件事。原三股试跑另有24个训练窗口、9个恒定教师字段和4个留出日期等证据，不能仅归咎于蒸馏机制。

因此，本轮验证到部分连续知识转移及极小的回溯方向增益，尚未验证到优于简单先验、优于无教师token建模、或双教师优于单教师的实用优势。下一轮优先验证向内部头提供因果归一化统计、稀有事件任务设计和教师梯度预算；需冻结新协议、用新时间窗口检验，并通过重复对照测量MPS数值波动。本轮未据留出结果继续训练、拟合校准器、恢复旧模型、晋升或导出合并模型。

四组消融尚未包含“冻结主干只训练教师读出头”和“打乱教师标签”的对照，因此不能仅凭辅助头重建改善和主干参数有差异，就精确区分教师语义、读出学习或一般辅助正则的贡献。当前“知识获取”结论限定为内部头对已知历史连续事实的重建；主干吸收和微弱方向增益的语义归因仍需这些额外控制。

主试验完成后，执行事前锁定检查点哈希的80股补充留出评分：1,813窗、80股、24日期、固定种子42。真实双教师LogLoss为0.940920591，打乱标签为0.940920910，差值仅-0.000000319，主要区间[-0.000144, +0.000151]。真实教师重建明显更好，但方向评分几乎相同，尚未确认双教师语义转移。冻结主干只训练头也能在连续重建上超过中位数；方向点估计较好但区间宽、选中步数不同，不能证明冻结主干普遍更优。ICT单教师在80股有小幅改善区间，但缺少专属打乱控制，且这不是独立市场日期复现。相同目标双教师重复一次的tune与留出评分一致，不能当作完整MPS噪声分布。
