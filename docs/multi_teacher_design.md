# CZSC 量价与 ICT 联合蒸馏设计

> 历史设计稿（2026-10-19 搭建阶段）。联合训练、原生 CZSC 头和四组消融现已接通；当前步骤及实际采用的损失配置以[蒸馏指南](distillation_guide.md)为准，实际验证见[240 股结果](results_240.md)。下文保留原阶段计划，不表示所有规划均已实现。

使用两个离线教师监督同一个 Kronos 学生：W32 提供量价与需求供给知识，ICT 提供经过时间确认的价格结构知识。教师表示相互关联，不能把它们当作独立投票重复提高置信度。未来收益方向仍以真实成熟行情监督。

```text
同一已核验历史窗口 ─┬─ 窗口内 W32 → 连续量价、事件、mask
                  ├─ ICT 原子教师 → swing 距离、FVG/sweep/close-break、mask
                  └─ 固定 tokenizer → Kronos + LoRA → 同一末位 hidden
                                                    ├─ W32 内部头
                                                    ├─ ICT 内部头
                                                    └─ 真实未来方向头
```

联合目标为原自回归损失、真实未来方向损失、W32 连续/事件损失、ICT 连续/事件损失，加保持 base token 分布的 KL。每个任务分别按有效 mask 求均值，未知项不参与损失；任务权重预登记，不因为某教师缺失而临时提高剩余教师的信心。模型主干 LoRA 必须实际更新。已有实现提供单项损失与多头结构，完整联合 batch/自回归训练仍待接线。

ICT 来源为用户指定的 [carreypro/ict-trading-model](https://github.com/carreypro/ict-trading-model)，固定 commit `7162437e28b1f59a4b25ea88615ee99902c9cc75`，保留 MIT 许可证和逐文件 SHA。该项目是规则及扫描器，不是可直接合并进 Kronos 的预训练神经权重。

首批 ICT 只学习可明确核验的日线原子目标：已确认高低 swing 到当前收盘的相对距离、当前完整三根 K 线形成的双向 FVG、当前对先前已确认 pivot 的双向 sweep 和收盘穿越。Swing 的 anchor 与右侧确认时间分开；FVG 依赖第三根收盘，不把中间根锚点当可用时间。普通收盘穿越不自动命名为 MSS、BOS 或 CHoCH，因为这些还依赖趋势和完整结构序列。

原扫描器的 composite candidate 会沿历史 sweep 检索之后的结构、回踩与失效。直接把最终结果贴回 sweep 日期会泄漏；逐原点截断能消除窗口外未来，却不能自动证明完整候选状态机的顺序和失效语义正确。因此首版不使用其 confirmed、候选目标或毛 R:R 监督，也不让它充当实际收益标签。原 vendor 保持不改，因果规则补充在本工程外部 adapter。

日线沪深数据无法提供纽约交易时段或执行级分钟结构证据；多周期、OB/Breaker/IFVG、OTE、premium/discount 及完整 setup 状态先明确 masked/pending。后续需要先确定可见 dealing range、阶段状态机和数据粒度，再新增 schema 与测试；不能从未实现项填造标签。若以后加入分钟/周线教师，也只能使用当时已经闭合且落在学生可见信息范围的上下文，或明确调整学生输入契约。

最小实验集合为 A 官方 base、B 普通 AR+方向 LoRA、C 仅 W32、D 仅 ICT、E 两者联合；最多6候选，保留一个预算位置给后续明确消融。B–E 使用相同学生架构、同样本和切分、训练预算、随机种子、未来标签、LoRA 容量、内部头及保持项，只改变已登记的教师损失。分别检查 C/B、D/B、E/C 与 E/D，避免把本地适应或更多训练步数当成教师贡献。

教师复现与未来预测分开评价；ICT 原子事件需要自然频率下 precision/recall/PR-AUC、确认延迟、边界质量与未知覆盖，不能只报大量无事件零值带来的 accuracy。最终仍检查方向 LogLoss/Brier、路径误差与有效率，再用独立 Broker/Ledger 做同风险规则的费用后研究。完整训练、执行资格和独立前瞻均未通过本轮目录搭建自动获得。
