# 800 股活跃样本消融：v0.2.0

2026-10-22 15:14（北京时间）完成，耗时约16小时44分钟。沪主板295、深主板271、创业板234；排除科创板和北交所。

筛选只使用2023年数据。预训练准入要求至少200根已验证日线、最后128个交易日完整；活跃池要求日成交额中位数至少2000万元、板块内波动分位至少0.4。按板块内成交额、收益波动、振幅和量能变化的分位数加权排名，权重0.35/0.35/0.15/0.15；板块配额按活跃合格人口比例分配，再取各板块最高分。实际入选股票日成交额中位数约1.94亿元，日对数收益波动中位数约3.17%。这是回溯活跃样本，不能代表全市场或无幸存者偏差人口。

## 训练与选点

共99,375个窗口，train/tune/calibration/policy/holdout分别55,544/12,095/5,343/8,402/17,991。上下文128根，未来5根，stride5；时间边界沿用240股研究。四组×三个种子（42/123/2026），每组27,772次更新、batch4，约两遍训练，总计333,264次更新。每6,943步评估tune，共初始点加四个季度点；12组均由tune选中6,943步的检查点。完成固定预算不等于最后一步就是所选模型。

官方主干及tokenizer冻结，外部q/v LoRA；所有配置、教师总预算和同种子初始化/抽样顺序匹配。数据生成、缓存、12组训练/重载评估、分析及适配器诊断均已完成，冻结文件复核通过。

## 留出方向结果

三种子均值，LogLoss与Brier越低越好。

| 配置 | LogLoss | Brier | 准确率 |
| --- | ---: | ---: | ---: |
| 无教师 | 0.912075 | 0.581923 | 46.5955% |
| CZSC | 0.912284 | 0.582103 | 46.5492% |
| ICT | 0.911910 | 0.581753 | 46.6270% |
| 双教师 | 0.912175 | 0.581988 | 46.5863% |
| 训练频率先验 | 0.879210 | 见JSON | 见JSON |

相对同种子无教师的LogLoss差值及主要95%描述区间：CZSC +0.000209 [-0.000474, +0.000932]；ICT -0.000164 [-0.001116, +0.000856]；双教师 +0.000100 [-0.000684, +0.000919]。三者区间均跨零，所有学生都弱于训练频率先验，尚不能确认蒸馏有稳定未来方向收益。

留出仅24个预测原点、17,991行；同日股票不是独立市场历史。区间按连续预测日期块保留所有股票和固定种子，属于描述统计。未来标签的疑似跳空质量过滤是事后准入，并非预测原点可部署筛选。800股同时改变样本构成和训练预算，跨240股指标变化不能单独归因于样本量。
